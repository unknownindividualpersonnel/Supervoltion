# Supervoltion

Supervoltion is an SNES emulator project. This repository initially contained only a README describing goals. I (GitHub Copilot) am beginning an iterative implementation in HTML + JavaScript. To see which games are compatible, see COMPATIBILITY.md.

## Goals
- CPU (65C816 at 3.58 MHz) emulation — WIP
- S-PPU 1 and S-PPU 2 chip emulation — WIP
- APU (SPC700) emulation — Not started
- Passed all checks in SNSP Aging — Not started
- Make a ROM boot — WIP (we can now load ROMs and inspect headers)
